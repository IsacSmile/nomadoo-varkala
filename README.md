# Nomadoo Varkala

Nomadoo Varkala is a web application designed for an eco-friendly kayaking, country boating, and stand-up paddleboarding experience located in the Paravur backwaters of Varkala, Kerala.

## Key Features

- Direct WhatsApp Reservation System: Pre-fills booking activity, preferred date, time slot, and guest names directly into a WhatsApp chat for immediate confirmation.
- Editorial Design System: Custom color palettes, backdrop blur overlays, responsive mobile cards, and clean typography.
- Interactive Activity Selection: Includes solo kayaking, tandem 2-seater kayaking, traditional country boating, semi-speed boating, and stand-up paddleboarding.
- Dynamic Showcases: Continuous media galleries showcasing location highlights and real customer tour videos.
- Administrative Dashboard (/admin): Internal management portal to view booking records, toggle status badges, track guest lists, search by name or phone, and manually log offline bookings. Newest entries sort automatically to the top with creation timestamps.
- Smooth Animations: Scroll-triggered section reveals and modal transitions built with Framer Motion.

## Technology Stack

- React 18 with TypeScript
- Vite for build tooling and fast development
- Tailwind CSS for responsive styling
- Lucide React for vector icons
- Framer Motion for smooth UI transitions

## Getting Started

### Prerequisites

Node.js version 18 or higher and npm installed on your machine.

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/IsacSmile/nomadoo-varkala.git
cd nomadoo-varkala
npm install
```

### Development Server

To run the local development server:

```bash
npm run dev
```

Navigate to `http://localhost:5173` in your web browser.

### Production Build

To compile static assets for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Administrative Dashboard

Access the reservation management interface by appending `/admin` to your website URL.
